# 联系方式共享单独同意说明 v1

生效范围：校园同行信息撮合服务的成团轮次。

当你选择同意成团时，平台会记录本说明的版本、当前成员快照和你的明确同意。只有本轮所有成员均确认、按账号支付信息服务费且同意仍有效时，平台才会向本轮成员提供彼此的微信号。

你可以撤回同意：

- 联系方式尚未解锁时撤回，本轮不会继续交付；已付款订单按本轮规则进入全额退款。
- 联系方式已经解锁后撤回，平台会阻止此后通过平台再次读取与你相关的联系方式。为避免成员被静默过滤后形成含糊披露，任一成员撤回后，整组成员都不能再读取本轮联系人；平台不会返回剩余成员的部分列表。
- 平台无法从已经查看、复制或保存信息的其他成员设备中技术性收回既有明文；请在确认前核对成员名单，并谨慎决定是否共享。

平台会记录每一次联系方式读取的请求标识、查看者、本轮、锁定政策版本和结果。成功读取还会记录被披露账号集合的不可逆摘要及数量，用于证明本次披露范围；不会在访问日志中保存微信号明文或账号列表。平台不提供司机、车辆、叫车、车费结算或运输服务。
