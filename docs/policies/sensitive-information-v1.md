# 学生认证敏感个人信息单独同意书（v1）

为确认校园同行功能仅向符合条件的在校学生开放，平台需要处理用户主动提交的企业微信身份截图和/或学生卡照片，以及学校、校区、学号 HMAC 摘要和学号后四位。

用户至少提交上述一种认证材料，也可以同时提交两种材料。平台不要求身份证、出生日期、完整学号长期存储或其他与学生认证无关的信息。用户应在上传前遮挡聊天内容、联系人、二维码、手机号、身份证号等审核不需要的信息。

认证材料存放于私有对象存储。仅经授权的审核员在密码、TOTP、校区权限、CSRF 与一次性访问凭证全部校验通过后受控查看；一次性凭证绑定到确切材料，不可改看同一申请中的另一张图片。所有查看、审核和删除操作均保留审计记录。

材料在待审核期间持续保留，以保证后台能够完成审核，不以“上传后 24 小时”为删除期限。审核通过、驳回或要求补充材料后，原始材料进入 24 小时删除倒计时。发生申诉、安全事件、存储或删除故障时，经审计批准可延长处理，异常保留原则上不超过 7 天。平台随后仅保留认证状态、材料类型、学校、校区、学号 HMAC 摘要、学号后四位、内容摘要、审核结论、政策版本和必要审计证据，不保留原图。

未提交的上传草稿会在上传凭证过期后进入删除队列。补交新材料时，被替换的旧对象会通过可重试的删除任务清理，不会因更换材料而误删新对象。

用户可撤回同意或注销账号。撤回不影响撤回前处理活动的效力，但平台将停止非履行法定义务所必需的后续处理，并按适用规则删除或匿名化相关信息。

勾选单独同意并提交材料，即表示用户已阅读并同意上述特定处理目的、处理方式、信息种类、保存期限与保护措施。
