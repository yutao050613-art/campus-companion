# 产品页面与后台信息架构

## 1. 小程序导航

底部四个入口：`首页`、`发布`、`我的同行`、`我的`。

| 页面 | 主要内容 | 关键权限/隐私规则 |
|---|---|---|
| 首页 | 校区、固定路线、日期、时间窗、匿名候选组 | 未认证可浏览路线，加入前必须认证 |
| 发布 | 路线、30分钟窗、1—3座、行李、性别偏好 | 服务端校验路线与重叠组；禁止自由地点 |
| 组详情 | 匿名昵称、认证标识、座位、截止时间、状态 | 解锁前不返回微信号和公开性别 |
| 成团确认 | 不可变成员快照、99分服务内容、锁定版本的共享同意 | ACCEPT 必须提交本轮政策版本；拒绝不扣费 |
| 支付 | 订单状态、退款条件、平台服务边界 | 金额只读；客户端成功只触发服务端查单 |
| 联系方式 | 当前轮次成员微信号、安全提醒、撤回入口 | 全员付款/授权；整组全有或全无；每次读取记录披露集合摘要；任一撤回后整组禁止新读取 |
| 我的同行 | 招募、确认、付款、已解锁、已结束 | 只显示本人相关组 |
| 学生认证 | 材料要求、首次上传/过期、审核、补交、资格到期和删除说明 | 状态无损保留时间历史；私有上传；不显示永久材料 URL |
| 安全中心 | 举报、拉黑、隐私授权、注销 | 高风险操作再次确认 |
| 政策 | 用户协议、隐私、退款、安全规范 | 展示不可变版本并记录同意版本 |

小程序不包含地图定位、司机端、车辆信息、车费计算、平台聊天或实时运输状态。

## 2. 运营后台

| 页面 | 能力 | 角色建议 |
|---|---|---|
| 仪表盘 | 匹配、成团、付款、退款、投诉指标 | ANALYST，只看聚合数据 |
| 认证审核 | 脱敏元数据、TOTP 后最长60秒单次凭证、平台代理材料、批准/拒绝、删除状态 | VERIFICATION_REVIEWER；不得取得COS URL，读取失败需重新认证签发 |
| 路线配置 | 校区、地点、方向、时间窗和启停 | ROUTE_MANAGER |
| 组队检索 | 状态时间线、轮次、匿名成员、异常 | SUPPORT，不默认显示微信号 |
| 订单/退款 | 对账、退款审批、失败重试 | REFUND_REVIEWER，退款需TOTP再认证 |
| 举报/风控 | 证据摘要、限制、申诉和解除 | TRUST_SAFETY |
| 管理员 | 角色、校区范围、会话撤销 | SUPER_ADMIN |
| 审计日志 | 敏感读取和变更记录 | AUDITOR，只读 |

角色可组合但默认最小权限。`SUPER_ADMIN` 不能绕过敏感读取审计，应用层不提供审计日志删除接口。

## 3. 首发路线种子候选

后台仅预置为停用候选，上线前根据实地调研启用：

- 白云校区正门 → 江高城际站及返向路线；
- 白云校区正门 → 滘心地铁站及返向路线；
- 白云校区正门 → 嘉禾望岗及返向路线。

地点正式名称、上下车安全区域和开放时段必须由运营确认，代码不硬编码。
